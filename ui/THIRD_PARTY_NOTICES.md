# 来源与许可

本扩展为独立实现，通过 CLI 和控制接口管理现有安装，不包含或重新分发 Mihomo 内核、节点配置或用户订阅。

- 管理对象：[nelvko/clashctl](https://github.com/nelvko/clashctl)，MIT License，Copyright (c) 2024–2026 nelvko。本版对接验证的 commit：cb609e8bdfc24559bbabbf3ce3c199be9e3e4ad2。
- 控制接口：[Mihomo API](https://wiki.metacubex.one/api/)。
- 扩展界面：[VS Code Webview API](https://code.visualstudio.com/api/extension-guides/webview)。
- 运行位置：[VS Code Remote Extensions](https://code.visualstudio.com/api/advanced-topics/remote-extensions)。
- 界面交互参考：[Clash Verge Rev 快速入门](https://www.clashverge.dev/guide/quickstart.html) 中的栏目组织与独立 TUN 开关，以及 [Mihomo 全局配置](https://wiki.metacubex.one/config/general/) 中的节点选择缓存。

本项目不隶属于上述项目或微软。插件图标和界面为本项目制作。
